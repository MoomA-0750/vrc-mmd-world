## 2026-09-27 MMD のモーションを外部ツールなしで Humanoid のクリップにする

- `.vmd` を ScriptedImporter で読み、MMD の標準ボーンに当てて足IKを解き、Humanoid のマッスル値にして焼く。MMD4Mecanim などの外部ツールは使わない
- 足の IK の目標も焼き、体格の違うアバターでも足が MMD の位置に着くようにした
- 焼き方を変えたら `VmdImporter.Version` を上げる決まりにした（上げないと Unity が取り込み直さず、古いクリップのまま動く）
- 根拠: 74ab89e、README「しくみ」「焼き方を変えたら」

## 2026-09-27 同期するのは時刻だけにし、踊りは各自の手元で合わせる

- 再生・停止・曲・開始時刻だけを同期し、音・お手本・踊りは各自の手元で時刻から合わせる
- ステーションのアニメーションは座った瞬間に先頭から始まり途中へ飛ばせないため、曲を区切り（既定 10 秒）に分けて区切りごとに Controller を作り、ステーションを枠ごとに2つ用意して乗り換える。降りて座り直すと一瞬立ち姿勢が見えるので、降りずに乗り換える
- 根拠: 74ab89e、a52f90f、README「踊らせ方」

## 2026-09-27 シーンは毎回作り直し、設定はマネージャーで扱う

- 曲・アバター・枠の数などは設定アセットに持ち、「ワールドを組み立てる」でシーンを毎回作り直す。手で置いたものは残らないので、変えたいところは組み立ての処理の方を直す
- 操作が一通り動くかは batchmode で流す自己テストで確かめる
- 根拠: 1efee04、README「曲を足す」

## 2026-09-27 踊りながら動く機能を試作し、ステーションの Mobile は採らなかった

- 試してやめた: ステーションの Player Mobility を Mobile にすると、踊りは流れるが体がステーションから離れた場所に残り、ステーションを動かしてもついてこなかった
- 代わりに、座ったままステーションの親（枠）を入力の分だけ動かし、その分を同期する方式にした（乗り物のワールドと同じ仕組み）
- 2026-09-28 に、この機能は初期設定で切った
- 根拠: 9964584、bfab0f8、bd0d5cf、7e634fa、README「踊りながら動く」

## 2026-09-27 VR で踊りを体に乗せるのに、アバター SDK の部品を各自で入れてもらう

- VR では座っていても頭・手・足がトラッキングのままで踊りを上書きし、足踏みのような見た目になる。VRC Animator Tracking Control を付ければ体を踊りに任せられるが、この部品はアバターの SDK にしかない
- SDK の DLL はリポジトリに入れられないので、各自で `Assets/LocalOnly` に写してもらう形にした
- 踊りの Controller のまま降りるとトラッキングが戻らないため、全身をトラッキングに戻すだけの Controller へ乗り換えてから降りる
- 戻す Controller を1つだけの変数で渡すと、VRChat がワールドを読み込めず Udon が動かなかったので、配列で渡すようにした（切り分けの commit を挟んで判明）
- 根拠: dfb0634、455e5ce、db64327、b5d6144、7a5ca27、README「VR で踊らせるのに要るもの」

## 2026-09-27 タブレットを手元に出す

- 踊っている間は体がステーションに固定され、舞台の横のパネルまで行けないため、手元に浮かぶタブレットで操作できるようにした
- Udon は KeyCode の配列を扱えないので、タブレットのキーは文字列で持つ
- 根拠: 33bd0f5、292143b

## 2026-09-28 体の向きはクリップに残し、ステーションは回さない

- 向きまでステーションで回すと、VR では視点も回っていた。向きはクリップで出し、ステーションは位置だけ動かすことにした
- 根拠: 7e634fa、f723419

## 2026-09-28 「その場で踊る」を人ごとに選べるようにし、「選ぶ」のページを作った

- 移動も入った元のクリップでステーションを動かさずに踊らせる実験をしたが、いったん取り消した（edd2a48 → 2a5e6f4）。このときは、座った人の体はステーションに固定されてクリップの移動は効かないと考えていた（のちに Tracking Control が無かったころの確かめ方だったと分かる。2026-10-02 の項）
- 枠ごとの紫のボタン（押すたびにアバターを切り替える）は使い方が分かりにくかったので外し、タブレットの「選ぶ」のページから枠にアバターを置く形にした
- 根拠: edd2a48、2a5e6f4、00f799b、`Editor/WorldBuilder.cs` のコメント

## 2026-09-28 配布物をまとめて落としても壊れないようにし、複数人のモーションに対応した

- MMD の配布物には踊り・表情・カメラの `.vmd` が混ざっているので、見分けてカメラは飛ばし、表情は踊りに重ねる
- 複数人のダンスはパートを枠の順に割り当て、立ち位置は配布物の位置のままステージの中央を原点にして踊る
- 手元のパネルを「左にモデル・中央に枠の列・右に曲の一覧」の形に作り直した（「選ぶ」のページはこのときに無くなったと読める（推測））
- 確認用に一時的に人形や2人目のパートを入れた commit は、その都度取り消している
- 根拠: 80c7a52、fa6584f、600ab13

## 2026-09-28 タブレットは左右どちらの手でも出せるようにし、ワールドに置けるようにした

- 左手固定をやめ、グリップを2回握った手に出す。もう一方の手で2回握ると持ち替える。同じ手で3回握るとワールドに置いて、片手だけで出して押せるようにした
- 根拠: 638b795、652a4df

## 2026-10-01 仮想の VR で確かめる仕組みを作った

- ヘッドセットなしで VR でしか起きないことを確かめるため、仮想 HMD のドライバと VMT、台本を流す `scripts/vrsim.py` を用意した
- 試してやめた: SteamVR の null ドライバは頭が原点から動かせず、VMT を頭にする TrackingOverrides も効かなかったので、HMD のドライバを自作した
- 使い終わったら仮想 HMD と VMT の登録も外す（残すと実機より先に HMD に選ばれ、偽のコントローラーが増える）
- これで見つけて直したこと: 座っている間は VRChat が InputGrab を送らない（グリップの軸を毎フレーム読むようにした）、踊っている間にワールドに置いたタブレットが体から離れる（ステーションに止めた）、降りるときの瞬間移動で指先がほかのボタンを押す（手前から押し込んだときだけ押す）
- 根拠: 722c1b2、b3b9961、2b98ee7、409dda6、560414f、ff2ed82、README「仮想の VR で確かめる」

## 2026-10-02 フォルダの `.vmd` を勝手に曲にするのをやめた

## 2026-10-02 VR の視点が揺れる問題: 移動をクリップに残し、ステーションは動かさない

- まず、振り付けの頭の動きで視点が揺れるとして、頭はトラッキングのままにする切り替えを足した（b488441）
- 仮想 VR で視点と頭の骨の位置を測り、原因は「移動を抜いたクリップで踊らせ、ステーションを軌跡どおり動かしていた」ことで、腰の揺れまでステーションごと動いて視点が揺れていたと分かった
- 振り付けの移動はクリップに残し、ステーションは曲の間動かさないようにした。視点は止まり、体も頭も踊る。「その場」は移動を抜いた Controller で踊る
- 「座った人の体にクリップの移動は効かない」という以前の理解は、Tracking Control が無かったころの確かめ方による誤りだった
- これで頭も踊りに合わせるのを初期で入れるようにした
- 根拠: b488441、0bf10cc、d50f7e1、5b70b99、828185b、README「踊らせ方」

## 2026-10-05 Quest とスマホに対応する

- Quest でも軽いように、ワールドのマテリアルは VRChat のモバイル用シェーダーにした（PC でも同じものを使う）。曲の音声は最初に全部読み込まれるので、Android では圧縮したまま持つ
- 床は見えなくした（本人の希望。当たり判定は残す）。モーションが始まったら枠の台座も隠す
- スマホの人は画面の隅の「メニュー」ボタンでタブレットを出し入れし、タップで押す
- 根拠: e04c79f、1125132、8c17d49、48242c6

## 2026-10-05 非公開でアップロードする道具を作った

- ワールド ID は `Assets/LocalOnly` に覚え、シーンには残さない（リポジトリに入れないため（推測））
- 新しいワールドでは、権利の確認を送るときに ID が空で失敗した。AssignId では ID が入らなかったので、`wrld_` + GUID で ID を作り、同意を送ってからアップロードする。SDK のパネルがまだサーバーに無い ID を消してしまうので、先にアップロード中の状態にしておく
- 根拠: b191a3d、5bb257f、6c4c822、9b55e17
